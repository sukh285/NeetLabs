

# NeetLabs - For your interview prep

**NeetLabs** is a full-stack coding practice platform designed to help students and professionals prepare for coding interviews in a more **structured, minimal, and learner-first way**.

Unlike traditional platforms that overwhelm learners with noise, NeetLabs focuses on **clarity, progress tracking, and problem-solving** — so you know exactly where you stand and how you’re improving.

---

## Why NeetLabs?

Preparing for coding interviews is tough. Most learners:

* Jump between multiple platforms without a clear path
* Lose track of progress over weeks/months
* Struggle to stay consistent and motivated

**NeetLabs** was built to fix this.
It’s not about chasing streaks or competing on volume — it’s about **making your prep structured and measurable**, without losing focus.

---

## Core Features

### 📝 Coding Problems

* Curated interview-style questions across **Difficulties, Companies and Algorithms**
* Each problem comes with:

  * Constraints
  * Examples
  * Hints & Editorials (to support learning, not shortcuts)
  * AI-supported guidance

### 💻 Code Editor & Execution

* In-browser editor (VS Code-like experience)
* Multi-language support (JavaScript, Python, Java)
* **Real-time code execution** powered by Judge0

### 📊 Progress Tracking

* Track solved problems across difficulties
* Detailed breakdown by **topic tags** (e.g. Arrays, DP, Graphs)
* Submission trends over the past weeks
* Accuracy rate & last activity
* Visual **charts** for progress tracking

### 🎯 Playlists (Custom Problem Sets)

* Create your own playlists of problems
* Add/remove problems easily
* Share sets to focus on specific topics

### 🧑‍💼 Profile Dashboard

* Visualize your coding journey with:

  * Line charts of submissions over time
  * Pie/radar charts for problem difficulty distribution
  * Tag-based strengths & weaknesses

### 🔒 Secure & Seamless

* JWT-based authentication
* OAuth login via Google and GitHub
* Role-based access for problem management
* Rate limiting & verification flows for extra security
* Plan-based access for users

### **Frontend**

* **React 19 + Vite 7** – Modern, fast UI framework
* **Tailwind CSS 4 + DaisyUI 5** – Minimal, responsive design system
* **MUI 7** – Charts and styled components
* **Framer Motion, GSAP, AOS, Spline 3D** – Advanced animations & visuals
* **React Hook Form + Zod** – Robust forms & validation
* **Zustand** – Lightweight global state management
* **Monaco Editor** – VS Code-like in-browser coding experience
* **Utilities**: Axios, Moment.js, Canvas Confetti, Heatmaps, Toast notifications

### **Backend**

* **Node.js 20 + Express 5** – High-performance backend
* **PostgreSQL + Prisma ORM** – Reliable relational database
* **Authentication & Security**: JWT, bcryptjs, Passport (Google & GitHub OAuth), express-rate-limit, sessions
* **AI Integration**: Gemini API (`@google/genai`)
* **Payments**: Razorpay SDK for subscription plans
* **Mailing**: Nodemailer + Mailgen for verification & notifications

### **Dev & Infra**

* **Vite** – Frontend bundler
* **ESLint + Prettier** – Code quality & formatting
* **Prisma Migrations** – Database schema evolution
